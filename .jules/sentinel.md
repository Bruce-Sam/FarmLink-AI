## 2023-10-27 - Fail Fast on Default Secrets in Production
**Vulnerability:** The application was configured to allow the use of a default `ADMIN_PASSWORD` ('AdminPassword123!') in all environments. If this configuration reached production, it could allow an attacker to gain full administrative access to the system using known default credentials.
**Learning:** Default credentials and secrets must be actively rejected in production environments. Relying solely on administrators to change them is insufficient and error-prone. The application should fail to start (fail fast) if critical security configurations remain set to their default, unsafe values in production.
**Prevention:** Implement explicit checks during the configuration loading phase (e.g., in `env.ts`) that throw errors if production environments use known default secrets (like JWT secrets, API keys, or default admin passwords). This guarantees the application cannot enter an insecure state in production due to misconfiguration.
